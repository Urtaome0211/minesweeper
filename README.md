# 扫雷 Minesweeper（C++ / Win32）

一个纯 C++ 实现的扫雷游戏，使用 **Win32 API + GDI** 绘制图形界面，**无需任何第三方库**，采用 **Windows 7 蓝色 Aero 风格**：蓝色渐变背景、光泽格子，并带翻开波浪、插旗弹出、地雷爆炸等动画。

## 源码结构（模块化拆分）

| 文件 | 说明 |
|------|------|
| `game.h` / `game.cpp` | 游戏核心逻辑（`Game` 类）：布雷、翻开、插旗、快速翻开、胜负判定、计时，以及动画时间戳 |
| `render.h` / `render.cpp` | GDI 绘制：蓝色渐变、七段数码管、光泽地雷/旗帜/数字/笑脸、翻开/插旗/爆炸动画 |
| `dialogs.h` / `dialogs.cpp` | 「自定义难度」对话框（内存对话框模板，无需 .rc 资源） |
| `app.cpp` | 程序入口 `WinMain`、窗口创建、消息处理、菜单、计时器、动画驱动 |
| `build.bat` | 编译脚本（调用本机 VS2026 的 MSVC 工具链） |
| `minesweeper.exe` | 编译好的可执行文件 |

## 运行

直接双击 `minesweeper.exe`，或在命令行执行：

```
minesweeper.exe
```

## 重新编译

双击 `build.bat`，或在「VS 开发人员命令提示符」中执行：

```
cl /O2 /std:c++17 /EHsc /utf-8 /DUNICODE /D_UNICODE game.cpp render.cpp dialogs.cpp app.cpp /Fe:minesweeper.exe user32.lib gdi32.lib msimg32.lib
```

> 注意：
> - 必须加 `/utf-8`，否则源码中的中文注释/字符串在 GBK 代码页下会被错误解析。
> - `/DUNICODE /D_UNICODE` 统一传给所有源文件，保证宽字符 API 一致。
> - `msimg32.lib` 提供 `GradientFill`，用于蓝色渐变背景。

## 玩法与操作

| 操作 | 功能 |
|------|------|
| 左键单击 | 翻开格子 |
| 右键单击 | 插旗 / 取消旗子 |
| 左右键同按（在已翻开的数字上） | 快速翻开周围（Chord） |
| 笑脸按钮 / `F2` / 菜单「新游戏」 | 重新开始 |

顶部面板：**左侧红色数字** = 剩余地雷数，**右侧红色数字** = 已用时间（秒）。

## 功能特性

- 三种预设难度 + **自定义难度**（行 5–40、列 5–60、任意雷数）
- 首次点击保证安全（点击处及其周围 8 格不放雷），并洪泛展开
- **Windows 7 蓝色 Aero 风格**：蓝色渐变背景、光泽格子
- **动画**：翻开时波浪式扩散、插旗弹出、踩雷后地雷依次爆炸、胜利逐格插旗
- 踩雷显示所有地雷、标错旗子打红叉、踩中的雷标红
- 胜利自动插满旗、笑脸变为墨镜
- 经典配色数字（1 蓝、2 绿、3 红……）
- 双缓冲绘制，无闪烁；支持 `WM_PRINT`，可被截图/打印工具正确捕获
